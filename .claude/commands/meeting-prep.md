# Meeting Prep Command

Run this command before important meetings to prepare effectively and ensure productive outcomes.

## Instructions

When the user runs `/meeting-prep [meeting name or time]`, help them prepare thoroughly:

### 1. Identify the Meeting

If meeting name/time provided:
- Locate in calendar (if MCP available)
- Confirm it's the right meeting

If not specified:
- Show upcoming meetings today
- Ask which one to prep for

### 2. Gather Meeting Context

Extract key information:

```
## Meeting Prep: [Meeting Title]

**Details**:
- Time: [Day, Date, Time]
- Duration: [X minutes]
- Location: [Room/Video link]
- Attendees: [List participants]
- Organizer: [Name]

**Time Until Meeting**: [X hours/minutes]
**Prep Time Available**: [Estimate realistic prep time]
```

### 3. Understand the Purpose

From calendar invite or user:

```
**Meeting Objective**:
[What's the goal of this meeting?]

**Your Role**:
[Are you presenting? Deciding? Participating? Listening?]

**Expected Outcomes**:
- [ ] [Decision to be made]
- [ ] [Information to share]
- [ ] [Problem to solve]
- [ ] [Action items to assign]
```

### 4. Review Background

Help user get context:

```
## Background Review

**Previous Related Meetings**:
- [Date]: [What was discussed/decided]
- [Date]: [Follow-up items from last time]

**Relevant Documents** (if available):
- [Doc 1]: [Brief description]
- [Doc 2]: [Brief description]

**Key Context to Know**:
- [Important background point 1]
- [Important background point 2]

**Open Questions from Last Time**:
- [Unresolved question 1]
- [Unresolved question 2]
```

### 5. Prepare Your Input

What to have ready:

```
## Your Preparation Checklist

**If You're Presenting**:
- [ ] Slides/deck ready and tested
- [ ] Demo prepared (if applicable)
- [ ] Handouts or links to share
- [ ] Backup plan if tech fails
- [ ] Anticipated questions + answers

**If You're Deciding**:
- [ ] Review decision criteria
- [ ] Understand options and tradeoffs
- [ ] Identify information gaps
- [ ] Consider stakeholder impacts
- [ ] Prepare clarifying questions

**If You're Participating**:
- [ ] Review agenda beforehand
- [ ] Prepare relevant updates
- [ ] Note questions to ask
- [ ] Bring supporting data if needed
- [ ] Clear on your position/opinion

**General Prep**:
- [ ] Read shared docs/links in invite
- [ ] Check in with key attendees beforehand
- [ ] Test video/audio if remote
- [ ] Clear schedule buffer after (no back-to-back)
```

### 6. Prepare Questions

Suggest questions to ask:

```
## Questions to Consider

**Clarifying Questions**:
- [Question about scope/requirements]
- [Question about constraints]
- [Question about timeline]

**Strategic Questions**:
- [Question about priorities]
- [Question about stakeholders]
- [Question about success metrics]

**Follow-up Questions**:
- [Question based on previous discussions]
- [Question about action item status]
```

### 7. Anticipate Challenges

Think ahead:

```
## Potential Issues & Responses

**Likely Objections**:
1. [Objection]: [How to respond]
2. [Objection]: [How to respond]

**Difficult Questions**:
1. [Tough question]: [Prepared answer]
2. [Tough question]: [Prepared answer]

**If Meeting Goes Off Track**:
- [Strategy to refocus]
- [Questions to ask to get back on track]

**If You Don't Know Something**:
- "Let me research that and follow up"
- "Good question - [colleague] would know better"
```

### 8. Set Personal Goals

What do you want to achieve:

```
## Your Meeting Goals

**Must-Have Outcomes**:
1. [Critical outcome]
2. [Critical outcome]

**Nice-to-Have**:
- [Secondary goal]
- [Bonus outcome]

**What You Want to Learn**:
- [Information to gather]
- [Perspective to understand]

**What You Want to Contribute**:
- [Value you'll add]
- [Expertise you'll share]
```

### 9. Logistics Check

Practical preparation:

```
## Logistics

**Technical Setup** (if remote):
- [ ] Video link works
- [ ] Camera/mic tested
- [ ] Background appropriate
- [ ] Lighting good
- [ ] Backup device ready

**Materials Needed**:
- [ ] Laptop/charger
- [ ] Notebook/pen
- [ ] Phone (on silent)
- [ ] Water
- [ ] [Any specific materials]

**Timing**:
- Meeting starts: [Time]
- You should join: [5 min early]
- Buffer before: [X min to prep/transition]
- Buffer after: [X min for notes/follow-up]
```

### 10. Quick Prep Summary

If short on time, provide condensed version:

```
## Quick Prep (5 Minutes)

**The 3 Things to Know**:
1. [Most important context]
2. [Key decision point]
3. [Your critical input]

**The 1 Thing to Bring**:
- [Essential material/data]

**The 1 Question to Ask**:
- [Most important question]

**Your Talking Points** (if asked):
- Point 1
- Point 2
- Point 3
```

## Example Output

```
# Meeting Prep: Q4 Planning Review with Sarah

---

## Meeting Details

**Details**:
- Time: Tomorrow (Nov 15) at 10:00am
- Duration: 60 minutes
- Location: Zoom (link in calendar)
- Attendees: You, Sarah Chen (Manager), Alex Park (Product)
- Organizer: Sarah Chen

**Time Until Meeting**: 18 hours
**Prep Time Available**: 30-45 minutes today

---

## Meeting Objective

**Purpose**: Review and finalize Q4 team objectives before submitting to leadership

**Your Role**: Present your draft objectives, get feedback, align on priorities

**Expected Outcomes**:
- [ ] Agree on 3-5 team objectives for Q4
- [ ] Identify resource needs and gaps
- [ ] Align on success metrics
- [ ] Get approval to move forward

---

## Background Review

**Previous Related Meetings**:
- Nov 1: Initial Q4 brainstorm (generated 12 ideas, need to narrow)
- Oct 15: Q3 retrospective (identified 3 areas to improve)

**Relevant Documents**:
- Your Q4 draft (sent Mon) - 7 proposed objectives
- Company Q4 priorities (from CEO email)
- Q3 results dashboard

**Key Context to Know**:
- Company focus: Revenue growth + product quality
- Team was stretched thin in Q3 (need realistic goals)
- New hire (Sarah) starts next week (factor into capacity)

**Open Questions from Last Time**:
- Which projects are must-have vs. nice-to-have?
- Can we get design support for new features?

---

## Your Preparation Checklist

**You're Presenting** (your objectives):
- [x] Draft objectives document (already sent)
- [ ] Prepare 2-min summary of each objective
- [ ] Have data ready: Q3 metrics, capacity analysis
- [ ] Prioritized list (if need to cut to fit capacity)
- [ ] Resource requirements clearly stated

**Materials to Prepare**:
- [ ] Pull Q3 performance data to support priorities
- [ ] Calculate team capacity (account for new hire ramp)
- [ ] Draft success metrics for each objective
- [ ] Note dependencies on other teams

---

## Your Preparation Checklist (Details)

**For Each Objective, Be Ready to Explain**:
1. Why it matters (business impact)
2. What success looks like (metrics)
3. How much it costs (time/resources)
4. What could go wrong (risks)
5. Why now (why Q4 vs. later)

**Your 7 Draft Objectives** (prioritize):
1. API Redesign - MUST HAVE (critical for scale)
2. Mobile app performance - MUST HAVE (user complaints)
3. Documentation overhaul - SHOULD HAVE (reduces support load)
4. New dashboard features - NICE TO HAVE
5. Payment system upgrade - SHOULD HAVE (security)
6. Analytics improvements - NICE TO HAVE
7. Testing automation - SHOULD HAVE (velocity)

**Realistic Capacity**: With new hire ramping, probably 4-5 objectives max

**Recommendation**: Lead with 1, 2, 5, 7 (must-haves + quality foundation)

---

## Questions to Consider

**Clarifying Questions**:
- "Which company priorities should we weight most heavily?"
- "What's our risk tolerance for Q4 - safe bets or stretch goals?"
- "Can we get dedicated design support, or work with existing capacity?"

**Strategic Questions**:
- "If we had to cut to 3 objectives, which matter most to leadership?"
- "Are there any surprise priorities I'm not aware of?"
- "How will these be evaluated at year-end?"

**Resource Questions**:
- "Can we hire contractors for documentation project?"
- "Is there budget for tools/services needed?"

---

## Potential Issues & Responses

**Likely Objections**:
1. "This seems like too much"
   → "Agreed - I prioritized as must/should/nice. Happy to cut to 4-5."

2. "Why isn't [X feature] on here?"
   → "Good point. Considered it but deprioritized because [reason]. Can add if you think it's critical."

**Difficult Questions**:
1. "Can you commit to all of these?"
   → "Not all 7 - realistically 4-5 given capacity. I've prioritized by impact."

2. "What if we don't get the new hire?"
   → "Then we'd need to cut to 3 objectives or extend timeline into Q1."

**If Meeting Goes Off Track**:
- "This is a great discussion - should we table for a separate meeting and focus on finalizing these objectives?"
- "We have 15 minutes left - can we make sure we align on the top priorities?"

---

## Your Meeting Goals

**Must-Have Outcomes**:
1. Agreement on final 4-5 objectives for Q4
2. Clear prioritization (what's P0 vs. P1)
3. Confirmation on resources available

**Nice-to-Have**:
- Early approval (vs. needing another meeting)
- Understanding of how this fits company goals
- Visibility into other teams' Q4 plans

**What You Want to Learn**:
- Sarah's priorities vs. yours (any misalignment?)
- How leadership evaluates success
- Political context (any hidden constraints?)

**What You Want to Contribute**:
- Realistic, well-thought-out plan
- Data-driven prioritization
- Confidence that we can deliver

---

## Logistics

**Technical Setup**:
- [x] Zoom link in calendar
- [ ] Test video/audio 5 min before
- [ ] Close Slack/email for focus
- [ ] Have water ready (60 min meeting)

**Materials Needed**:
- [ ] Draft objectives doc (open and ready)
- [ ] Q3 metrics dashboard (link ready)
- [ ] Notebook for action items
- [ ] Team capacity spreadsheet (in case asked)

**Timing**:
- Meeting starts: 10:00am
- Join by: 9:55am
- Before meeting: Review this prep (9:30-9:50am)
- After meeting: 15 min buffer for notes/follow-ups

---

## Quick Prep Summary (If Short on Time)

**The 3 Things to Know**:
1. You need to cut from 7 to 4-5 objectives - lead with API, mobile, payment, testing
2. Sarah wants realistic commitments (after Q3 being stretched thin)
3. This is your chance to align on priorities before work starts

**The 1 Thing to Bring**:
- Q3 metrics showing why API/mobile are critical

**The 1 Question to Ask**:
- "If we had to pick just 3, which would they be?"

**Your Talking Points**:
1. "I've drafted 7 but realistically we can do 4-5 well"
2. "API and mobile are must-haves based on Q3 pain points"
3. "New hire changes timeline - need 4-6 weeks ramp time"

---

## Action Items After Meeting

- [ ] Send updated objectives doc based on feedback
- [ ] Create Q4 project roadmap with timelines
- [ ] Follow up on open questions
- [ ] Share outcomes with team

---

**Confidence Check**: How prepared do you feel? 🟢 Ready | 🟡 Mostly | 🔴 Need more prep

Good luck! You've got this. 💪
```

## Customization Options

- `/meeting-prep [meeting]` - Full prep
- `/meeting-prep [meeting] --quick` - 5-minute condensed version
- `/meeting-prep --next` - Next meeting on calendar
- `/meeting-prep --today` - All meetings today
- `/meeting-prep [meeting] --export` - Save prep notes

## Use Cases

**Before Important Meetings**:
- Client presentations
- Executive reviews
- Performance discussions
- Stakeholder updates
- Decision-making sessions

**Routine Meetings** (lighter prep):
- Team standups
- 1-on-1s
- Check-ins
- Planning sessions

## Integration

- Uses Calendar MCP to pull meeting details
- Uses Email MCP to find related threads
- Uses Notion MCP to access shared docs
- Can save prep notes for reference

## Best Practices

- Prep 1-24 hours before (not right before)
- More important meeting = more prep time
- Always review agenda if provided
- Coordinate with co-presenters beforehand
- Leave buffer time after for notes/actions

## Notes
- Takes 5-45 minutes depending on meeting importance
- Reduces anxiety through preparation
- Increases meeting effectiveness
- Can be customized for meeting types
- Designed to ensure you show up ready
